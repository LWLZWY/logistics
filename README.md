# logistics
构建了一个面向跨境物流配载场景的多 Agent 辅助决策系统，用于解决人工配柜过程中规则复杂、费用核验困难、方案调整效率低的问题。项目将订单、柜型、港口、仓库、危险品属性、FBA 仓约束、报价规则等数据结构化输入，由“订单解析 Agent”完成订单分类与约束识别，“配载生成 Agent”生成候选单柜模式，“费用核验 Agent”调用规则库逐项计算海运、报关、清关、提柜、拆柜和尾程费用，“诊断 Agent”输出未覆盖订单、冲突热点和高成本模式。系统采用快慢两级评估：先用轻量规则筛选可行方案，再对高潜力方案进行精确费用校验，从而减少无效 token 消耗。相比纯人工反复试算，该系统能够显著缩短方案生成时间，并提高费用核验与异常定位的准确性。
